How to read these tables

The selected Gameweek shows results played before the next regular round begins. Postponed fixtures are included when they were actually played, not retroactively. P = played, W = wins, D = draws, L = losses, GF = goals for, GA = goals against, GD = goal difference, Pts = points. Optional columns include YC = yellow cards, RC = red cards, Sh = shots, SOT = shots on target, Cor = corners, F = fouls committed.

Enable Vs. final position to see how many places the club will rise or fall by the end of the season: dark green up = 4+ places gained, light green up = 1–3 gained, orange down = 1–3 lost, red down = 4+ lost, and equals = unchanged. For the current season, the final rank doesn't exist yet, so no comparison appears. Historical ranking follows points, goal difference and goals scored, with team-name fallback for unresolved ties; rare league tiebreakers and points deductions aren't yet modeled.
